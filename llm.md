## LLMs

#### Instalar anaconda
1. Instalar Anaconda
2. Crear environment
   1. descargar [environment.yml](https://manviny.github.io/llms/environment.yml)
   2. conda env create -f environment.yml
   3. conda activate llms

#### Ejecutar jupyter
1. [descargar cuaderno de jupyter](https://manviny.github.io/llms/resume_webs.ipynb)
2. conectar con ollama para usarlo en el cuaderno
3. jupyter lab
